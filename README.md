# 大小周历

大周上六天、小周上五天的排班日历与考勤工时计算器。一个单文件网页就能用，需要多人共用同一份排班时，再用自带的 PowerShell 局域网服务。

- 无需安装任何东西：只要浏览器（推荐 Edge / Chrome），服务端只用 Windows 自带的 PowerShell + .NET。
- 排班、工时、统计全部在页面里算，农历和法定节假日按《全国年节及纪念日放假办法》自动推算（适用 1900–2100 年）。

## 怎么用

### 方式一：自己一个人用（不联网也行）

直接双击 `大小周历.html`，或用浏览器打开它。配置和日常数据存在这台电脑的浏览器里（localStorage），换浏览器或清缓存前记得先「导出备份」。

### 方式二：局域网里同事一起看同一份排班

1. 双击 `启动局域网服务.bat`（首次运行会在同目录生成 `server-config.json`，默认端口 8080、默认管理员密码 `admin123`）。
2. 窗口里会打印本机访问地址和同事访问地址，例如：
   ```
   本机访问：   http://localhost:8080/
   同事访问：   http://192.168.1.20:8080/
   ```
3. 同事打不开就是防火墙拦了：双击 `配置防火墙规则.bat`（会弹 UAC，同意后按当前端口添加入站放行规则，可重复执行，每次先删旧规则再重建）。
4. 服务端把排班存在同目录 `data.json`，所有人看到的是同一份；只有登录过管理员的人能改，其他人只读（仍可查看日历、统计、导出 CSV）。

> 默认密码只是给你起步用的。第一次用请改 `server-config.json` 里的 `adminPassword` 再重启服务；这个服务不该暴露到公网。

## 页面功能

| 标签 | 能做什么 |
| --- | --- |
| 今日 | 今天的状态章（班 / 加 / 休）、农历与节日、本周是大周还是小周、距离下个大周还有几天，以及本月小结（上班 / 大周加班 / 休息 / 法定假 / 工时） |
| 月历 | 月视图，每格标注班 / 加 / 休 / 法定 / 手动上班 / 手动休息；点某天可直接改这一天的排班（例外不改变大小周轮转）；底部给出本月合计与「导出 CSV」 |
| 统计 | 选年份，给出每月上班天数柱状图和逐月表格（上班 / 工作日 / 大周 / 手动 / 休息 / 工时），最后一行是全年合计。整页按当前排班配置推算，不依赖已发生的打卡 |
| 设置 | 排班规则、手动例外、额外假期、备份与局域网服务相关操作 |

日格标记的口径：

- `班` 正常工作日；`加` 大周周末上班；`休` 休息日
- `休`（法定样式）国家法定节假日；`变` 手动改成上班；`例` 手动改成休息

## 排班规则

设置里几个字段决定了整张日历：

- **起始周一**：第一个大周的周一。整张日历都由它推算，若和公司人事排班错开一周，改这里就行。
- **大周节奏**：`起始周即大周` 或 `次周才是大周`，两周一个循环。
- **周末上班**：勾选周六、周日是否算上班日，以及是否「仅大周生效」（默认只在大周的周六上班，小周双休）。
- **每日工时**：1–16 小时，步长 0.5，用于工时汇总。
- **手动例外日**：每行一条，格式 `日期 上班/休息 原因`，例如 `2026-10-17 上班 项目紧急`。例外只影响这一天，不会让后面几周的大/小周错位。
- **额外假期**：单位自己的假期，同样一行一条，例如 `2027-03-08 妇女节半天`。

### 法定节假日的算法

按办法条文推算，不抄当年通知：元旦 1 天；春节 除夕 + 初一至初三（2025 年起含除夕，劳动节 2025 年起为 5/1–5/2，此前 5/1 一天）；清明 1 天（寿星公式推算）；端午、中秋各 1 天（由农历换算）；国庆 10/1–10/3。

官方通知里的搭桥连休、调休补班一律不标注——那属于当年的临时安排，法定节假日之外的补班日照常按大小周排班。法定日默认一律休息，如果你要那天上班，用「手动例外」改掉即可。

## 数据与备份

| 数据 | 存在哪 |
| --- | --- |
| 单机模式的排班配置 | 浏览器 localStorage，键 `daxz.v1` |
| 管理员登录凭据 | localStorage，键 `daxz.token`（局域网模式） |
| 局域网模式的排班 | 服务端同目录 `data.json` |
| 服务端口与密码 | 服务端同目录 `server-config.json` |
| 备份文件句柄 | IndexedDB（库名 `daxz`），清浏览器缓存通常不会被清掉 |

- **绑定备份文件**（需要浏览器支持 File System Access API，Edge / Chrome 可以）：选定一个 JSON 文件后，每次改动自动写进去。放在网盘目录也能同步；换电脑时把 `大小周历.html` 和这个 JSON 一起拷走、重新绑定就完整恢复。
- **导出 / 导入备份 JSON**：所有浏览器都可用；不支持文件绑定的浏览器请定期手动导出。
- **导出 CSV**：月历页底部导出当月考勤明细，文件名形如 `大小周_2026-11.csv`，含每日状态与当月合计。

局域网模式下页面每 5 秒向服务端问一次配置版本，管理员改了排班，其他人页面上会自动同步并弹提示；页面切到后台时不发这个请求。

## 深色 / 浅色主题

右下角的下拉框有三档：跟随系统、浅色、深色。选择记在 localStorage 的 `lh-theme` 键上（`auto` 时不写键），刷新和下次打开都保持；选「跟随系统」时系统切换深浅色会实时跟着变。

实现分三块，都在 `assets/` 里：

- `assets/theme.js` 挂在每个页面，负责控件、记忆与实时跟随；
- 页面 `<head>` 里那行内联脚本在首屏绘制前就把 `data-theme` 定好，所以不会先闪一下纸色再变深；
- `assets/theme.css` 是语义色板（变量名形如 `--lh-bg-*` 面、`--lh-ink-*` 墨、`--lh-line-*` 线、`--lh-shd-*` 影）加控件样式，同一个颜色在深、浅两档各有一个值，`大小周历.html` 只引用变量、不写死颜色。

禁用脚本或脚本被拦时，页面按 `:root` 兜底，也就是原本的纸色外观，功能不受影响。

## 局域网服务的接口

服务端是很薄的一层 HTTP 服务，只为这个页面提供共享配置：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` 或 `/index.html` | 返回 `大小周历.html` |
| GET | `/api/config` | 返回 `{cfg, mtime, admin}`；页面启动时用它探测有没有服务，`mtime` 用作数据版本号做同步 |
| POST | `/api/config` | 写入配置，必须带 `X-Admin-Token`，否则 401；字段会先校验修正再落盘 |
| POST | `/api/login` | `{"password":"…"}`，成功返回一个会话 token |
| POST | `/api/logout` | 丢弃当前 token |
| GET | `/api/session` | 只问「这个 token 还是管理员吗」，避免每次轮询都带配置 |
| GET | `/api/ping` | 存活检查（`{"ok":true}`），排查端口/防火墙时手动访问一下最省事 |

几个实现上的取舍，用之前值得知道：

- 请求体上限 4 MB，超了直接拒；空闲的 preconnect 连接等 500 ms 就关掉，不占着服务。
- 单线程串行处理请求，够用在小办公室，别拿它当公网服务。
- 会话 token 有效期 12 小时，过期后页面自动退回只读并提示重新登录。
- 数据写盘是整份 JSON 覆盖，没有并发锁；同一时刻只有一位管理员在改比较稳妥。

## 目录结构

```
大小周历.html        页面本体（日历、统计、设置、备份全在这里）
server.ps1           局域网服务：静态响应 + 共享配置 + 管理员会话
启动局域网服务.bat   双击启动，自动绕过脚本执行策略
配置防火墙规则.bat   提权后按当前端口放行入站 TCP，可重复执行
assets/theme.css     深浅两档的语义色板 + 主题控件样式
assets/theme.js      三态主题切换脚本
```

本项目不做 GitHub Pages 部署：数据要么留在本机浏览器，要么留在跑服务的这台电脑上，静态托管解决不了多人同步，反而容易让人误以为线上那份是最新排班。

## 常见问题

- **同事打不开页面**：先确认他访问的是窗口里打印的局域网 IP 而不是 localhost，再跑一次 `配置防火墙规则.bat`；端口被占用时服务会直接报错退出，改 `server-config.json` 里的 `port` 换个端口。
- **日历和公司排班差一周**：改「起始周一」，或把「大周节奏」从「起始周即大周」换成「次周才是大周」。
- **明明是该休的日子显示上班**（或反过来）：那一天多半是手动例外，在月历里点开那天 →「取消例外（按大小周）」。
- **换电脑**：单机用户在旧机器「导出备份 JSON」，新机器打开页面后「导入备份」；绑定了备份文件的，直接把那个 JSON 拷过去重新绑定。
- **设置里的框是灰的、没有保存按钮**：那是局域网模式的只读状态，需要点右上角「管理员登录」。管理员登录后保存才会写进 `data.json`，其他人刷新就能看到新排班。
